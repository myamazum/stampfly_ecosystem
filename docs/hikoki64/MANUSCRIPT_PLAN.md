## 4. 批判的レビューで特定した弱点と手当て（2026-07-02 実施済みレビュー）

| # | 弱点 | 手当て |
|---|------|--------|
| ① | 新規性の位置づけ欠落（フロー+ToF位置保持自体は既存） | 1章に関連研究と差分を明示。売りは「実効ゲイン欠損の定量同定＋ロバスト再設計の過程」 |
| ② | 「ゲイン低下でなぜ発散？」（普通は安定側）への説明欠落 | 4章に時間スケール分離崩壊の機構説明＋余裕の数値。`poshold_loop_design.py` から図を再生成 |
| ③ | 因果の輪が未閉鎖（K同定→ゲイン変更→解消、の間に他要因の可能性） | **SILプラントに同定Kを注入し旧ゲイン発散再現・新ゲイン安定を示す**（最優先の追加実験、オフラインで可能） |
| ④ | 性能数値の内部不整合（±6-7cm vs 3分飛行の平均13cm、「RMS16mm」の定義曖昧） | 指標を数式定義し、フライトごとに条件付きで正直に報告。電池電圧の低下は考察の材料に回収 |

### 章別の想定質問と防御（原稿に書き込む問答）

- **2章**: 位置ループがP主体（pos.ti=5）→ 屋内・微風前提＋積分強化の弊害（リポジショニング巻き上がり）を1文。
- **3章**: フロー速度スケーリングにESKF自身の推定高度を使う自己結合 → EKF標準線形化の範囲＋高度はToF直接観測で拘束、と1文防御。運動加速度補償を「改善」と主張する場合は `eskf_replay` によるON/OFFアブレーション必須（やらないなら設計記述に留める）。
- **4章**: 「フロー過小読み0.66は校正で除去すべきでは」→ 個体差・床面・電圧で変動する量ゆえ点校正でなく変動域へのロバスト設計を選んだ、と設計思想として本文に書く。「トルク効き0.4-0.7はどの機体か」→ 6月に機体交換履歴あり。**どのログがどの機体かを原稿内で一貫させる**。個体差があるからこそロバスト設計、の論理に回収。
- **5章**: 再現性（フライト本数・床面・照度）を正直に明記。
- **6章**: 「SILが予見できないのは当然では」→ SILの限界の発見ではなく Model Identity 還流サイクルの実証として書く。

## 8. 方針改訂（2026-08-02 著者指示による再定位）

### 論文の立ち位置（確定）
- **主眼**: 著者が開発した StampFly の初の学術文書化——機体パラメータの開示と位置制御系の
  設計手順の体系的整理。**新規性は主張せず淡々と**。「初」は「StampFly としては初」に限定
  （Crazyflie に同ジャンルの前例があり、それこそが模範）
- **読みどころ**: 開発過程で生じた**小型機（37g）ゆえの困難・予想外とその対処**。
  同種の困難が Crazyflie 文献で既報のものは引用して「その知見が使える」ことも書く
- **基盤**: 実機と同一ソースの SILS を独自開発し、StampFly で制御を学ぶ人の基盤を
  構築していることを紹介
- 4章の発散事例は verification_findings_20260802.md の判定に従う
  （精密σ・ω撤回、K掃引安定境界で説明）

### Crazyflie 調査の帰結（2026-08-02、内容検証済み。詳細は terminology.md 文献表）
- 模範文献: Förster 2015（同定・全文読了）、Giernacki+ 2017（教育プラットフォーム・全文）、
  Greiff 2017（設計手順・全文）、Eschmann+ 2024（モータ遅れ検証・該当箇所）、
  Mueller+ 2017（EKF理論・アブストのみ）、Bitcraze 公式文書群
- **小型機の困難は全て既報**: モータ個体差（Eschmann）、電池電圧低下の補償（Giernacki 式(5)、
  Greiff、Bitcraze 2025）、フロー床面依存・ドリフト（Bitcraze、Greiff）、
  モータ遅れ T_m≈65〜73ms（Förster/Eschmann/公式の3者近接）、EKF工夫（Mueller）
  → 困難の「発見」を新規と主張せず、対応付けで引用する
- **StampFly 固有と言える点（調査の結論）**:
  1. 実機と完全同一ソースの決定論的 SILS——Crazyflie 公式には存在せず
     （GitHub discussion #995 で非サポート明言）、CrazySim（ICRA2024）は
     「実機書込禁止の改造フォーク」と README 明記
  2. パラメータ開示＋設計手順＋小型機の困難を単一文書に統合した形式
     （Crazyflie では複数文献に分散）
  3. xy 閉ループ位置保持精度の直接数値——Crazyflie 文献に公表値が見当たらず、
     ±6〜7cm の報告自体に資料価値
- Crazyflie 側の位置保持の最近接値: Greiff の高度推定 std≈1.6cm 等（xy の直接値なし）
