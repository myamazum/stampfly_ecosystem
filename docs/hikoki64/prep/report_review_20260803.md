## 教訓

- n=5 の相関係数を因果的な文脈で提示するのは脆弱（窓の取り方で符号まで変わる）。
  頑健なのは窓別統計の直接比較
- 「機械走査の DIVERGENT 判定」は文脈（モード・スティック・診断）と併せて初めて意味を持つ
  ——判定基準の事前固定と、判定後の指揮側精査の両方が必要
- 記述と実装の不一致（ToF vs ESKF推定高度）は、コードの該当行まで降りるチェックリスト層で
  しか見つからなかった
