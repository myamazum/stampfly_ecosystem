# SIL 同定ゲイン注入実験の結果（2026-08-02）

計画 §5 項目1（旧・弱点③「因果の輪を閉じる」）の実験記録。**結論: きれいな定性
再現は得られず、論文3.3節は計画どおりフォールバック（線形モデルの安定限界計算）
を用いる。**

## 実験系

SIL プラントに opt-in の2ノブを新設（既定1.0=従来とバイト一致、既定挙動の不変は
既存シナリオ実走で指揮側も再確認済み）:
- `torque_authority` — 4モータ推力を平均まわりに再配分し**差動成分のみ**縮小
  （正味鉛直推力は厳密に不変）。平均も縮める既存 `thrust_efficiency` では 10〜20% の
  縮小で離陸不能となり、実機の症状（離陸・ホバーは可能で姿勢達成度のみ低下）と
  矛盾するため分離した
- `flow_vel_scale` — フロー画素出力の乗数（過小読み 0.66 の模擬）
- CLI: `sf sil scenario --torque-authority R --flow-scale R`

## 結果（4条件×2試験）

| 試験 | 旧+理想 | 旧+欠損(0.55/0.66) | 新+欠損 | 新+理想 |
|------|---------|--------------------|---------|---------|
| 大きな再配置(~0.7m) | 保持 | 保持 | 保持 | 保持（全条件で出力リミット・アンチワインドアップの飽和が支配し差が出ない） |
| 微小変位(~cm・線形域) | 周期~9秒の非減衰持続振動 RMS 0.081m | 同型 RMS 0.073m | 小振幅 RMS 0.021m | 小振幅 RMS 0.016m |

- **旧ゲインは「理想プラントでも」持続振動**（現在の SIL プラントは6月時点から
  大幅に改修されており「6月のSIL」は再現不能）。torque_authority 掃引
  （1.0→0.15）でも単調な悪化は見られず、欠損注入の単独効果を分離できなかった
- 一貫して確認できたこと: **新ゲインはプラント条件によらず旧ゲインの3.5〜5倍
  タイト**

## 論文への帰結

- 3.3節は「SILで発散を再現した」とは**書かない**。乖離の説明は線形モデルの
  安定限界（旧ゲインは K/g≈0.64〜0.80 が限界、K=g で安定・K=0.4g で不安定）と、
  検証済みの同定値（0.58×0.66）で行う（フォールバック、v3計画に明記済み）
- 2ノブは今後のロバスト性スタディ用のSIL機能として保持（既定OFF・退行なし）
