## 2. 新たに判明した事実

1. **発散飛行の記録は14.5秒しかない**。σ・ω の精密同定にはそもそも足りない（極値4点）。
   文書の 9.4 s / 0.057 という数値は、この記録長では確定不能な精度で書かれていた。
2. **実傾き→計測速度ゲインの強い周波数依存**（検証B, L3/L4）: 0.5〜1 rad/s帯で
   ≈0.21〜0.29、広帯域(0.2〜3 rad/s)で ≈0.62〜0.69。低周波ほど減衰する形は
   ロータ抗力（速度比例抗力 d·v）の予言と定性一致。広帯域値はフロースケール0.66と整合。
3. **軸非対称**: 姿勢達成度は pitch(0.85〜0.97) が roll(0.58〜0.68) より明確に良い
   （7/17-18、コヒーレンス0.66〜0.98）。
4. **設計スクリプトの較正循環に注意**: `poshold_loop_design.py` は OBS_OMEGA=0.683・
   OBS_SIGMA=0.057 を目標に K=0.41g へ自己較正している。σ・ω が上記のとおり
   要再検討である以上、「K はσ・ωから逆算した」経路は使えない。ただし K の実体
   （0.58×0.66）は `poshold_attID.py`（別の手動ウォブル飛行・広帯域回帰）由来で、
   検証Bが独立に再現したため **K≈0.4g 自体は生き残る**。
5. **`poshold_attID.py` の適用範囲**: docstring 明記のとおり ALT_HOLD スティック・
   ウォブル飛行専用（POS_HOLD ログには非適用）。同定は 0.15〜3 Hz 帯域通過後の
   切片なし回帰＝広帯域値であり「0.68 rad/s の点」ではない。論文の「ω≈0.68近傍の値」
   という記述予定は**「0.15〜3 Hz 帯の回帰値」に訂正が必要**。
6. テレメトリの status 電文はレートゲインのみ記録（姿勢・位置ゲインは非記録）。
   条件再現性のための配線課題。
7. モデル(K=0.4g)の予測発振周波数 ω≈0.70 rad/s と、再計測した実発振 ω≈1.30 rad/s も
   一致しない（2倍差）。周期の食い違い（判定#2）と同根の可能性。短記録ゆえ
   「どちらのモードが不安定モードか」をデータから確定できない。

## 3. 論文4・5章への統合判定

**書ける（検証済み）:**
- SIL合格ゲインが実機で約15秒で発散した事実（時系列図で示す）
- 専用ウォブル飛行からの同定: 姿勢達成度≈0.58・フロー系≈0.66 → 実効ゲイン≈0.4g
  （帯域 0.15〜3 Hz の回帰値と明記。3週間後・レートゲイン3倍後も同水準で再現＝頑健）
- 線形カスケードモデルの安定境界: 旧ゲインは K/g≈0.64〜0.80 が境界、K=g では安定
  → SIL（理想プラント）合格と実機（K≈0.4g）発散の乖離をモデルで説明
- 再設計（内側強化＋外側減速＋K×τ変動域でロバスト化）と、その後の
  **記録24飛行・計約25分**（多様な条件・レートゲイン3構成を跨ぐ）で
  同型発散の再発なしという実地実証（変動域設計の価値）

**訂正記録（2026-08-02、2段階）**:
1. 本報告の初版および関連文書に「62日」という期間が記載されていたが、出典のない
   誤記（正値26日の数字転置、または同定むだ時間62msとの混同の疑い）。著者の指摘で
   検出し訂正した。
2. さらに著者の指摘「26日間何もしなくても26日」により、**暦日数という指標自体が
   証拠として無意味**と判明。飛行記録の実測（ログの推力>0.02窓の合計）に基づく
   「飛行回数・飛行時間・条件の多様性」へ置換した: 再設計後 6/22〜7/18 に27ログ・
   飛行24回（>5s）・計1505s≈25.1分。内訳: 6/22夜10回（再設計当日の検証）、
   6/24×2、6/27×4（3分連続飛行177s・展示会場150.7s/123.7s含む）、6/29×2
   （177.9s含む）、7/17×5、7/18×2。レビューパケット・レビュー原本（prep/review/）
   は当時の記録として旧記載のまま保存する。

**書けない・書き方を変える:**
- 「周期9.4 s・σ=+0.057/s の成長リミットサイクル」という精密な記述 → 撤回。
  「約15秒で振幅が増大し壁に至った（記録長の制約から成長率の精密同定は不能）」へ
- モデルと実測の「極の一致」主張 → 不可（ω が2倍ずれる）。モデルの役割は
  「安定/不安定の境界と傾向の説明」に限定する
- 「ω≈0.68 rad/s近傍での同定値」という表現 → 「0.15〜3 Hz帯の回帰値」へ
- 「今のレートゲインでも発散は起きた」とまでは断定しない（反実仮想）が、
  「達成度欠損はレート再調整後も持続」という測定事実は6章の材料になる

**6章（考察・課題）の新材料:**
- 傾き→速度ゲインの周波数依存（低周波減衰）とロータ抗力仮説 → モデル高度化の課題

- 発散のモード構造（x: 4.8s振動 vs y: 低速発散）の未解明 — 短記録の限界

## 5. 検証の方法メモ（再現性）

- 検証A: 発散ログ 20260622T161055 の位置時系列に対し、周期図（df=0.069Hz）・
  ゼロクロス・極値間隔で周波数、Hilbert包絡/極値列/窓振幅の指数fitでσ（AIC比較付き）。
  モデルは poshold_loop_design.py の関数を無改変流用し K=2.0〜10.0 を掃引。
- 検証B: 4ログ共通スキーマ解読→ status からゲイン・電圧復元→ angle_ref↔quat姿勢、
  姿勢↔ESKF速度の Welch クロススペクトル（コヒーレンス<0.5は推定不能と申告、
  合成データで手法を事前検証、SOSフィルタで数値安定化）。
- 両検証とも poshold_journey.md・reports・hikoki64 文書の閲覧を禁止した状態で実施。
