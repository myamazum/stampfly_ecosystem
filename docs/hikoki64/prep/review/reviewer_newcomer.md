# 構成レビュー: 「StampFly の位置制御に関する一考察」（第64回飛行機シンポジウム講演集原稿・6章構成案）

**レビュアーの立場**: StampFly を一切知らない制御工学者。パケットに書かれた情報のみを根拠とし、他文書は参照していない。以下、章を読み進める順に「何を期待し、どこで裏切られるか／迷子になるか」を追いながら評価する。

---

## 0. 時系列読者体験（章を追って何を期待し、どこで崩れるか）

**題目を見た時点**（読み始める前）: 「StampFly の位置制御に関する一考察」。「一考察」という控えめな言い方から、位置制御まわりの設計・チューニングについて一つの視点から論じる、比較的こぢんまりした技術ノートを想像する。パラメータ同定や墜落寸前の事故談が中心テーマになるとは予期しない。

**1章「はじめに」を読了した時点**: 37g のクアッドロータで、Crazyflie を規範に位置づけ、フロー閉ループの先行研究4件を引用し、「文書化と教訓」を宣言する、と理解する。ここで「教訓」という語が出るので、後段に何らかの失敗談があることはうっすら予感するが、それがどの程度の重み（分量・ドラマ性）を持つ章になるかは全く分からない。この時点で立てる仮説は「これは設計論文＋やや実務的な失敗談の付録」というものであり、後述するように4章を読むとこの仮説は裏切られる。

**2章「機体と開発環境」を読了した時点**: 諸元と同定パラメータの表（むだ時間・モータ時定数・推力ゲイン・傾き→速度ゲイン等）、開発フロー、SILS の1段落紹介、を得る。ここが本レビューの核心的な懸念点である。**この論文の一次目的（パラメータ開示）の一番濃い数値がここに置かれているにもかかわらず、章タイトルは「機体と開発環境」——読者の心構えとしては"前提条件の確認"であり、"結果の開示"ではない。** 制御屋の読者は通常、こういう章を軽く読み飛ばして本題（3章の設計）に進む。しかし実際にはここに、3週間後・内側ゲイン3倍化後も再現したという頑健な回帰結果（0.4g・0.58×0.66分解、0.15〜3Hz帯）という、この論文で最も手間のかかった実験結果が埋もれている。**同定の方法論（どうやって測ったか）がこの章のどこに収まるのかが構成案から読み取れない**——「開発フロー」に含まれるのか、単に表だけが天下り的に出るのか不明。制御屋の読者はほぼ確実に「このむだ時間62msとT=20msはどうやって出したのか」を知りたがるので、方法論の置き場所が曖昧なのは大きなリスクである。この章を終えた段階で、読者はまだ「この論文が何の論文か」を確定できない——ハードウェア紹介なのか、同定結果報告なのか、これから始まる設計論のための前置きなのか、読者の頭の中で3つの仮説が併存したままになる。

**3章「位置制御系の設計」を読了した時点**: カスケードPID・ESKF・フロー処理という設計の本体に到達し、「design→SILS検証→実機」という手順で書かれる、とある。ここでようやく「これは設計論文だ」という仮説が確証される。しかし同時に新しい疑問が生まれる——ここで開示されるゲイン値・設計は**最終版（4章の再設計後）なのか、それとも当初版（4章で発散する版）なのか**。構成案からは判別できない。もし3章が最終ゲインを提示しているなら、読者は「この設計手順で作った、と3章で読んだのに、4章でいきなり『このゲインは実機で発散して壁に激突した』と言われる」という強いどんでん返しに遭遇する。逆に3章が当初ゲインなら、「設計手順の整理」という一次目的の成果物として開示される数値が、後で自ら否定される暫定版だということになり、"参照起点"としての価値が下がる。**この曖昧さは構成表からは解消できておらず、3章と4章の間に論理の飛びがある。**

**4章「小型機ゆえの困難と対処」を読了した時点**: ここで初めて、SILS で安定確認済みのゲインが実機で約15秒のうちに発散し壁に衝突する、という最もドラマチックな材料が登場する。安定境界の掃引図・K/g≈0.64〜0.80・変動域ロバスト再設計・62日間の安定持続——これは制御屋にとって非常に読みごたえのある内容であり、率直に言って**この論文で最も面白い部分はここである**。しかし問題は、この最も強い材料が二次目的（困難の共有）に属し、しかも紙幅は3章（一次目的の本体）と同じ1.25pである。読者は4章を読み終えた時点で、「この論文は実は"位置制御の設計論文"ではなく"小型機の制御破綻と復旧のケーススタディ"だったのではないか」という読後感を持ちかねない。これは題目「位置制御に関する一考察」からは全く予期できない読書体験である。加えてこの章は、発散事例＋実効ゲイン同定＋電池サグ等の他困難＋ロバスト再設計＋62日持続＋SILS合格と実機発散の乖離＋同定値のSILSへの還流、と**6つの下位トピックと2枚の図を1.25pに収める**必要があり、密度が高すぎて個々の話が数行ずつの羅列になるおそれが強い。

**5章「到達点と課題」を読了した時点**: 3つの異なる飛行日・条件のホバリング性能数値（±6-7cm/RMS16mm、放し飛行RMS6.9cm、3分飛行drift13cm+電圧相関）に加え、限界（床面・個体差・電池）・課題（高度・周波数依存・軸非対称）・今後（軌道・代替制御器・外部測位）という4系統の話を0.75pに詰め込む。ここで読者は既視感に襲われる——**電池・床面依存・個体差は4章で「困難と対処（Crazyflie既報対応付け）」として一度扱われたはずなのに、5章では「限界」として再度出てくる。** 対処済みなのか未解決なのか、章をまたいで整合しているのか、読者は混乱する。また3つの性能数値が条件も日付も異なる状態で並記されると、初見の読者には「結局この機体の位置保持精度は何cmと言えるのか」が一読では掴みにくい。

**6章「まとめ＋参考文献」を読了した時点**: 0.5pに要約と文献12件を収める設計になっている。文献12件を2段組で列挙するだけでも相当な行数を要するため、まとめの文章は実質1〜2文程度しか残らない可能性が高い。

## 1. 目的への奉仕度

パケット記載の目的序列は 一次＝パラメータ開示＋設計手順整理（参照起点）／二次＝困難と対処の共有（Crazyflie対応付け）／三次＝SILS紹介、である。

- 紙幅配分だけを見ると、一次目的（2章1.0p＋3章1.25p＝2.25p）＞二次目的（4章1.25p単独）であり、序列は一応守られている。
- しかし**「単独の章としての最大値」で比べると4章（二次目的）が3章（一次目的の本体）と同点、2章（一次目的の一部）を上回る**。二次目的が一次目的の個々の章と紙幅的に対等以上に扱われているのは、序列付きの目的設定と緊張関係にある。とりわけ4章はドラマ性が高く記憶に残りやすいため、読後感としては二次目的の方が主役に見えるリスクがある。これは配分の絶対値の問題というより、**「読者の記憶に残る順位」と「著者が意図する目的の優先順位」が逆転しかねない**という設計上のリスクとして指摘する。
- 三次目的（SILS紹介）は2章（導入1段落）・3章（設計手順内の1ステップ）・4章（合格/発散の乖離＋同定値の還流）と**3箇所に分散**している。紙幅としては小さく抑えられており序列相応だが、一箇所にまとまった説明がないため、読者はSILSが結局「何であり、今どこまで検証が進んでいるか」を一枚絵として掴めない。三次目的なりに「紹介する」という達成基準を満たすには、せめて一箇所に要点を集約すべきである。

## 2. 弱点・リスク

1. **3章と4章の時系列関係が未確定（論理の飛び）**: 3章で提示される設計・ゲイン値が「発散前の当初設計」なのか「4章の教訓を織り込んだ最終設計」なのか構成案から読み取れない。これは読者に強い混乱を与えるリスクが最も高い箇所である。
2. **2章に一次目的の核心数値が"前提条件"の体裁で埋没**: 最も苦労して得られた同定結果（頑健性込み）が、読者が読み飛ばしがちな「機体と開発環境」という章タイトルの下に置かれている。同定の方法論の置き場所も不明。
3. **4章の過密（詰め込みすぎ）**: 6下位トピック＋図2枚を1.25pに収める設計。特に「同定値のSILSへの還流」は**未実施（発表までに実施予定）の実験**に依存しており、これが間に合わない・定性再現に失敗する等のリスクが、章の構成上の前提になってしまっている。
4. **4章と5章の内容重複・整合未確認**: 電池サグ・床面依存・モータ個体差が4章「困難と対処」と5章「限界」の両方に現れる。4章は「対処済み」、5章は「未解決の限界」という異なる含意を持つはずだが、構成表からはその書き分けの方針が見えない。特に電池サグは「Crazyflie文献に補償式の明示例がある」ことが4章の材料として挙がっているが、これは**StampFly自身が対処した事実ではなく「他機に解法があると引用した」だけ**の可能性が高く、「困難と対処」という章タイトルの"対処"がStampFly自身の対処なのか文献紹介なのかが曖昧なまま構成が固まっている。
5. **5章の過密（薄すぎ・詰め込みすぎの両面)**: 0.75pに性能3系統＋限界＋課題＋今後の4トピックを収める。特に性能数値は日付・条件が異なる3種類が並ぶため、紙幅が足りないと読者は数値の意味を取り違えかねない。
6. **図表の密度が全体として高い**: 図候補7点（うち2点は表）が4.25p（2〜5章）に分散。特に3章（複雑なカスケード線図＋フロー処理6段パイプライン図を1.25pに収める）と4章（安定境界図＋発散時系列を密なテキストと同居させる）で、図の可読性を保ったまま紙幅に収まるか疑問。
7. **6章の紙幅不足**: 文献12件を2段組で並べるだけで0.5pの相当部分を使う可能性が高く、「まとめ」の実質的な内容が数文に切り詰められるおそれ。
8. **1章の過密**: 動機・Crazyflie位置づけ・関連研究4件・「文書化と教訓」宣言の4つの役割を0.75pに収める。特に関連研究4件のレビューを地の文で書くと紙幅を圧迫するため、表形式などの圧縮手段が必要になる可能性がある（構成案には明記なし）。
9. **SILSのyaw合否情報の置き場所が不明かつ題目とのスコープ不一致の疑い**: 材料にある「roll/pitch合格・yaw不合格」は、位置制御（並進）というより姿勢・機首方位寄りの話であり、「位置制御に関する一考察」という題目のスコープからやや外れる。どの章に置くか構成表に明記がなく、置き場所を決めないまま原稿に流れ込むと、脱線として浮く危険がある。

## 3. 対案

**対案A（本命）: 3章と4章の関係を明示的に再設計し、「困難と再設計」を"設計の一部"として組み込む**
- 3章の冒頭または末尾に、次の一文で橋渡しを明示する:「本章で示す設計は当初案であり、4章で述べる実機発散を経て最終化された（最終ゲインは4章末に示す）」、あるいは逆に「本章の数値はすでに4章の教訓を反映した最終形である」——どちらかを明言し、章間の時系列を確定させる。
- より強い対案としては、**4章の内容を3章の一部（3.x節）として統合**し、「3. 位置制御系の設計」の中に「3.1 カスケード構造」「3.2 状態推定」「3.3 実機での破綻と再設計（現4章の主要部）」という流れを作る。こうすると「設計→SIL検証→実機」という3章の手順記述が、そのまま4章の破綻談へ地続きに接続し、読者が「あれ、さっき手順が機能すると読んだのに」と感じる段差が消える。この場合、章番号は5章構成（はじめに／機体と同定／設計と実機検証（旧3+4）／到達点と課題／まとめ）に圧縮でき、紙幅は 0.75 / 1.0 / 2.25 / 0.9 / 0.6 ≒ 5.5p程度で再配分可能。困難パートが「設計」に内包されることで、二次目的が一次目的を食う懸念（1節参照）も自然に解消する。

**対案B: 2章から同定結果を独立させ、「同定」章を新設**
- 現2章を「2. 機体と開発環境」（諸元＋開発フロー＋SILS紹介、軽量化して0.6p）と新設「3. パラメータ同定」（同定手法＋結果表＋頑健性の確認、0.75p）に分割する。同定こそが一次目的の核であるという位置づけを、章タイトルレベルで明示する。以降の章番号を1つずつ繰り下げる。
- この対案は対案Aと両立可能（同定章→設計章→（対案Aで統合された）実機検証・困難章、という流れ）。両方を採用する場合、全体は7章構成程度になるため、1章の関連研究レビューを表形式に圧縮するなど他所で紙幅を捻出する必要がある。

**対案C: 4章と5章の重複解消**
- 電池サグ・床面依存・個体差は、StampFly自身が対処を実装・検証したものだけを4章「困難と対処」に残し、対処していない（Crazyflie文献を参照するのみの）ものは5章「限界」に一本化する。同じ事象を両方の章で扱うのをやめ、章の役割分担（4章＝解決済み／5章＝未解決）を厳密化する。

**対案D: 4章の「SILSへの還流」実験を条件付き構成にする**
- 「同定値をSILSに注入して発散を定性再現する」実験が発表までに完了しない場合に備え、この内容を4章の本文ではなく5章「今後の課題」側に予備的に位置づけておく。完了すれば4章に格上げ、未完なら5章の課題として書く、という二段構えにしておくことで、未実施実験への依存によって章の骨格が揺らぐリスクを避けられる。

## 4. 材料との整合

- **材料は全体として豊富であり、死んでいる材料はほぼ見当たらない**（文献12件・図7候補・性能数値3系統・同定パラメータ一式・困難談・SILS、いずれかの章に対応付けられている）。
- ただし**紙幅に対して図表候補が多すぎる**（7図候補÷4.25p(2〜5章)）。特に3章（カスケード線図＋フロー処理6段パイプライン）と4章（安定境界図＋発散時系列）は、図を縮小しすぎて可読性を失うか、テキストを削って図に紙幅を譲るかの二択を迫られる可能性が高い。全図を等しく使うのではなく、**教育的価値の低い図（例: フロー処理6段パイプラインの詳細図）を表または簡略ブロック図に格下げする**などの取捨選択が必要になるだろう。
- **同定の方法論という「材料」が構成表に明示的な置き場所を持たない**。0.15〜3Hz帯の回帰、姿勢達成度0.58×フロー系0.66への分解、3週間後・ゲイン3倍化後の再現性確認——これらは方法論としての説明が要る材料だが、現状は「2章の同定パラメータ開示表」という結果提示の中に暗黙的に含まれるのか、別途書かれるのか不明。一次目的（参照起点を作る）を本気で達成するなら、この方法論こそが後続の研究者にとって最も再利用価値が高い部分であり、構成上の明示的な居場所を与えるべきである。
- **5章の性能数値3系統は、紙幅0.75pでは条件差の説明が追いつかない可能性が高い**。表形式（性能条件表は図候補として既にある）に条件（日付・飛行モード・時間）を整理して埋め込むことで初めて0.75pでも成立し得るが、地の文中心で書くと確実に紙幅超過するか説明不足になる。
- **未実施実験（SILS発散再現）が4章の一部として構成に組み込まれている**ことは、材料整合の観点で最大のリスクである。これは「使える材料」リストではなく「未実施」として明記されており、構成案がこれを前提に4章の内容を書いている（「同定値のSILSへの還流もここ」）以上、発表までに完了しなければ4章はその部分だけ差し替えが必要になる。

## 5. 題目「StampFly の位置制御に関する一考察」との整合

- 「一考察」という控えめな題目に対し、実際の構成は（a）パラメータ同定表の開示、（b）安定余裕解析を伴うロバスト再設計の事故・復旧談、（c）SILS基盤の紹介、という**3つの異質な内容クラスタ**を含んでおり、単一の視点からの「考察」というより「開発報告＋同定＋障害対応記録」の複合文書に近い。題目の穏やかさと構成の情報量に落差がある。
- 最も紙幅の大きい単独の物語（4章の発散・復旧談）は、二次目的に属するにもかかわらず題目からは全く予期できない内容であり、初読の制御屋は「位置制御の設計論文」を期待して読み始め、4章で「これは小型機特有の制御破綻ケーススタディだった」と認識を更新することになる。この認識更新自体は悪いことではない（むしろ読み物として引き込まれる）が、**題目が予告していない**という点で構成との整合に難がある。
- また、材料中の「yaw不合格」情報のように、並進位置制御という題目のスコープから外れかねない要素が、置き場所未定のまま構成に潜在している。
- 対案としては、（i）題目はそのままにして対案A/Bで構成を「設計→検証→再設計」の一体化した物語に組み替え、「一考察」の名にふさわしい単線的な流れに寄せる、（ii）題目に同定・検証のニュアンスを含める（例:「StampFly の位置制御系設計と実機同定に基づく検証」）、のいずれかを検討すべきである。ただし題目は「既定」とパケットに明記されており、変更提案が許容される前提かは著者の判断による。

## 総合判定

構成の大枠（導入→機体・環境→設計→困難→到達点→まとめ）自体は学会講演集として不自然ではない。しかし、**(1) 3章と4章の時系列関係が未確定であることによる論理の飛び、(2) 一次目的の核心（同定結果と方法論）が"前提条件"として埋没していること、(3) 4章と5章の困難/限界の重複と役割分担の曖昧さ、(4) 未実施実験への依存、(5) 図表密度に対する紙幅の逼迫**、の5点は、いずれも「読者が構成のどこかで迷子になる」実質的なリスクである。特に(1)は、この論文が"何の論文か"を1章・2章で確定させるべきという評価軸に照らすと、3章を読み終えてもなお確定しない、という点で最も重い指摘である。対案A（困難パートを設計章に統合し時系列を一本化する）が最も費用対効果の高い修正だと考える。
