\section{はじめに}
% 内容メモ（0.75p想定）:
%   - 用語は docs/hikoki64/terminology.md（慣用検証済みリスト）に従う。
%     本章での方針: 「非GPS環境」（○）／「実効ゲイン」は1章では説明的表現に留め
%     4章で初出定義／「飛行データ」（「飛行ログ」は使わない）／SILS表記。

本稿は，質量37\,gの超小型クアッドロータ（quadrotor）StampFly（図\ref{fig:stampfly-photo}）
を対象とした，屋内における位置制御の開発過程を報告するものである．無人航空機（ドローン）の
応用が屋内の点検・物流や教育・研究へと広がるにつれ，GPS等の衛星測位が利用でき
ない非GPS環境における位置の推定と制御の重要性が増している．とりわけ質量数十
グラム級の機体は，人や設備への危害の危険性が小さく屋内での反復実験が容易である
ことから，制御工学の教育・研究用プラットフォームとして有用である．

StampFly は著者が開発に携わった M5Stack 社の市販の開発用機体であり，下方の
床面を観測するオプティカルフローセンサと ToF（Time of Flight）測距センサを
標準搭載する．本研究では，状態推定と制御系を含む飛行制御ソフトウェアを新たに
開発し，搭載センサのみを用いて位置制御系を構成した．この種のセンサ構成による
位置制御には，オプティカルフローと測距に
よる速度推定をオンボードで実現した PX4FLOW\cite{honegger2013}，Bitcraze 社
Crazyflie 用の Flow Deck\cite{flowdeck}，数十グラム級機体への実装
\cite{mcguire2017}，国内グループによる飛行制御への適用\cite{kendoul2009}など
多くの先行例があり，本稿は手法そのものの新規性を主張するものではない．

本稿の主眼は，開発過程で遭遇した「シミュレーションでは安定，実機では発散」
という乖離の解明と解決の過程にある．実機と同一の制御ソフトウェアを実行する
SILS（Software In the Loop Simulation）で安定を確認した位置制御系が，実機では
飛行開始から約15秒のうちに水平方向の変位が増大する発散を生じた
% src: verification_findings_20260802.md #1（飛行窓14.5s・radial 0.07→0.75m）
．そこで飛行データから，傾き指令に対して実際に
得られる速度応答のゲインを同定した結果，理想値の約4割まで低下しており，その
内訳が姿勢応答の未達とオプティカルフローによる速度の過小評価との積で説明できる
ことを明らかにした．さらに，同定値を1点の校正値として扱うのではなく，機体の
個体差や環境条件による変動域を仮定してロバストに安定となるよう制御系を再設計し，
実機でホバリング時の位置誤差 $\pm 6$〜$7$\,cm を確認した．最後に，同定したゲインを用いた線形モデルの解析により，当時の設計が不安定と
なる条件と再設計後の安定を確認し，実機で同定した特性をモデルへ反映する
開発サイクルの有効性を示す
% src: verification_findings_20260802.md #5（SILでの発散再現は不成立のため線形モデルで説明: sil_injection_20260802.md）
．なお，StampFly を対象とした学術報告は
著者の知る限り見当たらない．

以下，2章で機体と開発環境，3章で位置制御系の設計と実機での再設計，4章で
小型機ゆえの困難，5章で到達点と課題を述べ，6章でまとめる．

StampFly の開発は，制御系の設計，SILS（Software In the Loop Simulation）による検証，実機飛行，実機飛行で得た飛行データからのシステム同定，同定結果の制御系モデルへの反映という手順を繰り返すループとして進めている．
% TODO: 開発フロー図（後日TikZ）
設計変更はまずSILS上で検証し，問題がなければ実機に反映する．実機飛行で得られた飛行データはオフラインでの同定に用い，同定して得た値は制御系のモデルおよびSILSのプラント（機体運動を模擬する数値モデル）の双方に反映する．設計段階のゲインやフィルタ定数はこのループを通じて段階的に更新される値であり，最終的な推奨パラメータは3.4節にまとめて示す．

SILSは，実機ファームウェアと同一のソースコードを無改変のままホスト計算機向けにコンパイルし，決定論的に実行する検証環境である% src: docs/hikoki64/prep/gap/sf_ecosystem.md \S2.2
．ESP-IDF／FreeRTOS依存部分をホスト向けスタブに置き換えることで，実機と同じPub-Sub構造の制御ソフトウェアをそのまま動かす．同じソースコードが実機とSILSの双方で動くため，SILSでの合否は設計変更の実機挙動への影響を見積る手掛かりとして使う% src: firmware/vehicle/docs/development_roadmap.md:41--54
．ノイズ・外乱は種（シード）付き乱数で与えており，同じ種であれば実行のたびに同一の出力が得られる% src: docs/hikoki64/prep/gap/sf_ecosystem.md \S2.3
．回帰試験には40本のシナリオを用い，起動・状態遷移，推定の追従性，閉ループの安定性，アクチュエータの健全性という4種類の数値合格基準（ゲート）で自動判定する% src: docs/hikoki64/prep/gap/sf_ecosystem.md \S2.4
．さらに，同一の同定手順をSILSと実機双方の飛行データに適用して結果を数値で突き合わせる仕組み（モデル一致ゲート）を備えており，2026年7月26日時点の計測ではロール・ピッチ軸は合格，ヨー軸は不合格である% src: docs/hikoki64/prep/gap/sf_ecosystem.md \S2.6
．SILSはあくまで理想化したプラントに基づく検証であり，実機との一致は今後も確認を要する項目である旨は5章で改めて扱う．

\section{位置制御系の設計と実機での再設計}
\label{sec:design}

\subsection{カスケード構造とPID形式}

位置制御系は，位置$\rightarrow$速度$\rightarrow$姿勢$\rightarrow$角速度の4段カスケード構造からなり，
全段が単一の制御周期400\,Hz% src: pid_controller.hpp:443-448（ControlTaskはIMU同期400Hz）
で，同一の呼び出し内に逐次実行される（外側・内側ループ間の分周は行わない）% src: firmware_position_control_report.tex §3.1（compute()内で分周パターン不検出）
．位置ループ（P，出力は速度指令 $v_\mathrm{sp}$\,[NED, m/s]）% src: pid_controller.cpp:1326-1327
の出力は速度ループ（PID，出力は加速度指令 $a_\mathrm{ned}$\,[m/s$^2$]）% src: pid_controller.cpp:1332-1333
へ渡り，速度ループの出力は機体座標系へヨー回転した後，微小角近似
$\theta \approx a/g$ により傾き指令へ写像される
（$\mathrm{pitch}_\mathrm{sp}=-a_{x,\mathrm{body}}/g$，$\mathrm{roll}_\mathrm{sp}=a_{y,\mathrm{body}}/g$% src: pid_controller.cpp:1350-1351
，重力加速度 $g=9.80665$\,m/s$^2$% src: sf_math.hpp:39, pid_controller.hpp:223
，$\pm 10$\textdegree（0.1745\,rad）% src: pid_controller.hpp:224
でクランプ）．傾き指令は姿勢ループ（PID，出力は角速度指令 $\mathrm{rate}_\mathrm{sp}$\,[rad/s]）% src: pid_controller.cpp:455-456
を経て，最内周の角速度ループ（PID，出力はトルク指令 [Nm]）% src: pid_controller.cpp:774-776
へ渡る．全段のPID制御器は共通の伝達関数

\[
C(s)=K_p\left(1+\frac{1}{T_i s}+\frac{T_d s}{\eta T_d s+1}\right)
\]
% src: pid.hpp:14
を持つ．ここで $K_p$ は比例ゲイン，$T_i$\,[s] は積分時間，$T_d$\,[s] は微分時間，
$\eta$ は不完全微分係数（既定 $\eta=0.125$）% src: pid.hpp:54
である．微分は目標値でなく測定値に作用させる方式（D-on-M）により目標値ステップでの
微分キックを避け% src: pid.hpp:20-31
，積分は台形則と条件付き積分アンチワインドアップ（出力が飽和方向に押される場合は
積分更新を停止する）を併用する% src: pid.hpp:108-133
．角速度ループが出力するロール・ピッチ・ヨートルクおよび鉛直推力指令は，
X型配置の4個のモータ% src: requirements.md:149-156
への推力配分（以下，ミキサ）によって個々のモータ回転数指令へ変換される．

\subsection{状態推定}

状態推定には15状態の誤差状態カルマンフィルタ（Error-State Kalman Filter, ESKF）を用いる
（状態は位置・速度・姿勢誤差・ジャイロバイアス・加速度バイアスの各3次元）% src: eskf_core.cpp:14, eskf_core.hpp:36-40
．オプティカルフローの生出力（画素変位）は，ジャイロ計測値を用いて回転による見かけの
流れ成分を除去したのち% src: eskf_core.cpp:751-752, eskf_core.hpp:88（flow\_gyro\_scale=1.0）
，ToFで得た高度でスケーリングして機体座標系の並進速度に変換し% src: eskf_core.cpp:756-757
，ヨー回転を経てNED座標の速度観測としてスカラー更新する% src: eskf_core.cpp:761-784
．品質指標SQUALが閾値（既定10）% src: eskf_core.hpp:100, params.cpp:808
を下回るサンプルおよび高度0.02\,m% src: eskf_core.hpp:89
未満のサンプルは観測から棄却する．外れ値混入への対策として，イノベーションに対する
$\chi^2$ゲート（自由度3，有意水準0.95に対応する閾値7.81）% src: eskf_core.cpp:448-462, params.cpp:812
をはじめとする複数のロバスト化機構を備える．

\subsection{SILS検証から実機発散，実効ゲイン同定，再設計まで}

SILSによる検証に合格したカスケードで臨んだ初の実機飛行（2026-06-22）では，
離陸から約15\,秒% src: 飛行窓14.51s, verification\_findings\_20260802.md \#1（確定）, paper\_figs.py flight\_window
のうちに水平方向の変位（動径 $r=\sqrt{x^2+y^2}$）が0.07\,mから0.75\,mへ増大し% src: verification\_findings\_20260802.md \#1, logs/stampfly\_udp\_20260622T161055.jsonl
，壁に至って飛行を終えた（図\ref{fig:divergence}）．この乖離の原因を探るため，
専用のスティック加振飛行データから，指令傾きに対する実傾きの達成度
$\approx 0.58$% src: verification\_findings\_20260802.md \#4（再現・頑健）, poshold\_journey.md:152-154
と，オプティカルフロー由来の速度のスケール $\approx 0.66$% src: verification\_findings\_20260802.md \#4
（いずれも0.15--3\,Hz帯の回帰値）% src: verification\_findings\_20260802.md \#5（訂正記録）
を同定した．両者の積として，実効的な「傾き→速度」ゲインは理想値 $g$ の
約0.4倍（$K\approx 0.4g\approx 3.9$\,m/s$^2$/rad）% src: poshold\_journey.md:150, verification\_findings\_20260802.md \#4
にとどまっていたことが分かった．線形カスケードモデルによる解析では，当時のゲイン
（位置ループ $K_p=1.0$，速度ループ $K_p=0.8$）% src: task2\_pole\_sweep.py GAINS\_O（旧ゲイン）
は，むだ時間 $L=150$\,ms% src: paper\_figs.py TAU\_PRIMARY=0.15s（K掃引の代表値）
において $K/g\approx 0.64$--0.80が安定限界であり% src: verification\_findings\_20260802.md \#5
，これを下回ると不安定となる（例: $K=3.9$\,m/s$^2$/radで支配極の実部
$\sigma\approx+0.08$〜$+0.11$）% src: verification\_findings\_20260802.md \#5
．一方，SILSが内部プラントに仮定する理想ゲイン $K=g\approx9.81$\,m/s$^2$/radでは
安定（$\sigma\approx-0.07$〜$-0.12$）% src: verification\_findings\_20260802.md \#5
であり，この差がSILS合格・実機発散の乖離を説明する（図\ref{fig:stability}）．
% 注意: 「SILSで発散を再現した」とは書かない（sil_injection_20260802.md の帰結．3.3節は線形モデルの安定限界計算で乖離を説明する）
以上を踏まえ，単一の同定値への点校正ではなく，$K\in[2.8,7]$\,m/s$^2$/rad，
$L\in[50,300]$\,ms% src: poshold\_journey.md:175
という変動域全体で安定となるようカスケードを再設計した（速度ループゲイン
0.8→3.0，位置ループゲイン1.0→0.4）% src: poshold\_journey.md:170-173, params.cpp:771,773
．この再設計は同日中の実機飛行を経て，暫定値（位置ループ1.0→0.3，速度ループ
0.8→2.0）% src: poshold\_accel\_compensation.md:199-210（2026-06-22初回飛行時点の暫定値）
から，最終値（位置ループ0.4，速度ループ3.0）% src: poshold\_journey.md:170-173, params.cpp:771,773
へ確定した．
