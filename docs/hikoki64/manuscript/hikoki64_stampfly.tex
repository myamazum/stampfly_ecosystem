\section{はじめに}
% 内容メモ（0.75p想定）:
%   - 用語は docs/hikoki64/terminology.md（慣用検証済みリスト）に従う。
%     本章での方針: 「非GPS環境」（○）／「実効ゲイン」は1章では説明的表現に留め
%     4章で初出定義／「飛行データ」（「飛行ログ」は使わない）／SILS表記。

%
本稿は，質量37\,g
% src: pid_controller.hpp:407（kMassG）
の超小型クアッドロータ（quadrotor）StampFly（図\ref{fig:stampfly-photo}）
を対象とした，屋内における位置制御の開発過程を報告するものである．無人航空機（ドローン）の
応用が屋内の点検・物流や教育・研究へと広がるにつれ，GPS等の衛星測位が利用でき
ない非GPS環境における位置の推定と制御の重要性が増している．とりわけ質量数十
グラム級の機体は，人や設備への危害の危険性が小さく屋内での反復実験が容易である
ことから，制御工学の教育・研究用プラットフォームとして有用である．一方，搭載
できるセンサや計算資源が限られるという小型機の制約の下で，位置保持の制御が
どの程度成立するかは実機での確認を要する．本稿はこの問いに実機での実測を
もって答える．

StampFly は著者が開発に携わった M5Stack 社の市販の開発用機体であり，下方の
床面を観測するオプティカルフローセンサと ToF（Time of Flight）測距センサを
標準搭載する．本研究では，状態推定と制御系を含む飛行制御ソフトウェアを新たに
開発し，搭載センサのみを用いて位置制御系を構成した．この種のセンサ構成による
位置制御には，オプティカルフローと測距に
よる速度推定をオンボードで実現した PX4FLOW\cite{honegger2013}，Bitcraze 社
Crazyflie 用の Flow Deck\cite{flowdeck}，数十グラム級機体への実装
\cite{mcguire2017}，国内グループによる飛行制御への適用\cite{kendoul2009}など
多くの先行例がある．光流の閉ループ応用の系譜としても，移動プラットフォーム
への光流フィードバックによる自動着陸\cite{herisse2012}，機上の光流のみによる
閉ループ速度制御\cite{grabe2012}，固定翼機における30\,g級機体での光流を用いた
操縦\cite{zufferey2005}などが報告されており，本稿は手法そのものの新規性を
主張するものではない．

本稿の主眼は，開発過程で遭遇した「シミュレーションでは安定，実機では発散」
という乖離の解明と解決の過程にある．実機と同一の制御ソフトウェアを実行する
SILS（Software In the Loop Simulation）で安定を確認した位置制御系が，実機では
飛行開始から約15秒のうちに水平方向の変位が増大する発散を生じた
% src: verification_findings_20260802.md #1（飛行窓14.5s・radial 0.07→0.75m）
．そこで飛行データから，傾き指令に対して実際に
得られる速度応答のゲインを同定した結果，理想値の約4割まで低下しており
% src: poshold_journey.md:150（K≈0.4g=0.58×0.66）
，その
内訳が姿勢応答の未達とオプティカルフローによる速度の過小評価との積で説明できる
ことを明らかにした．さらに，同定値を1点の校正値として扱うのではなく，機体の
個体差や環境条件による変動域を仮定してロバストに安定となるよう制御系を再設計し，
実機でホバリング時の位置誤差 $\pm 6$〜$7$\,cm を確認した
% src: poshold_journey.md:177-182
．最後に，同定したゲインを用いた線形モデルの解析により，当時の設計が不安定と
なる条件と再設計後の安定を確認し，実機で同定した特性をモデルへ反映する
開発サイクルの有効性を示す
% src: verification_findings_20260802.md #5（SILでの発散再現は不成立のため線形モデルで説明: sil_injection_20260802.md）
．なお，StampFly を対象とした学術報告は
著者の知る限り見当たらない．

以下，2章で機体と開発環境，3章で位置制御系の設計と実機での再設計，4章で
小型機に特有の困難と対処，5章で到達点と課題を述べ，6章でまとめる．

StampFly の開発は，制御系の設計，SILS（Software In the Loop Simulation）による検証，実機飛行，実機飛行で得た飛行データからのシステム同定，同定結果の制御系モデルへの反映という手順を繰り返すループとして進めている．
% TODO: 開発フロー図（後日TikZ）
実機飛行で得られた飛行データはオフラインでの同定に用い，同定して得た値は制御系のモデルおよびSILSのプラント（機体運動を模擬する数値モデル）の双方に反映する．設計段階のゲインやフィルタ定数はこのループを通じて段階的に更新される値であり，最終的な推奨パラメータは3.4節にまとめて示す．

SILSは，実機ファームウェアと同一のソースコードを無改変のままホスト計算機向けにコンパイルし，決定論的に実行する検証環境である% src: docs/hikoki64/prep/gap/sf_ecosystem.md \S2.2
．ESP-IDF／FreeRTOS依存部分をホスト向けスタブに置き換えることで，実機と同じPub-Sub構造の制御ソフトウェアをそのまま動かす．同じソースコードが実機とSILSの双方で動くため，SILSでの合否は設計変更の実機挙動への影響を見積る手掛かりとして使う% src: firmware/vehicle/docs/development_roadmap.md:41--54
．ノイズ・外乱は種（シード）付き乱数で与えており，同じ種であれば実行のたびに同一の出力が得られる% src: docs/hikoki64/prep/gap/sf_ecosystem.md \S2.3
．回帰試験には42本のシナリオを用い，起動・状態遷移，推定の追従性，閉ループの安定性，アクチュエータの健全性という4種類の数値合格基準（ゲート）で自動判定する% src: simulator/sil/scenarios/*.scn 実測42本(2026-08-03; ゲート分類はsf_ecosystem.md §2.4)
．さらに，同一の同定手順をSILSと実機双方の飛行データに適用して結果を数値で突き合わせる仕組み（モデル一致ゲート）を備えており，2026年7月26日時点の計測ではロール・ピッチ軸は合格，ヨー軸は不合格である% src: docs/hikoki64/prep/gap/sf_ecosystem.md \S2.6
．SILSは理想化したプラントに基づく検証であり，実機との一致は5章で改めて扱う．

\label{sec:design}

\subsection{カスケード構造とPID形式}

位置制御系は，位置$\rightarrow$速度$\rightarrow$姿勢$\rightarrow$角速度の4段カスケード構造からなり，
全段が単一の制御周期400\,Hz% src: pid_controller.hpp:443-448（ControlTaskはIMU同期400Hz）
で，同一の呼び出し内に逐次実行される（外側・内側ループ間の分周は行わない）% src: firmware_position_control_report.tex §3.1（compute()内で分周パターン不検出）
．位置ループ（P，出力は速度指令 $v_\mathrm{sp}$\,[NED, m/s]）% src: pid_controller.cpp:1326-1327
の出力は速度ループ（PID，出力は加速度指令 $a_\mathrm{ned}$\,[m/s$^2$]）% src: pid_controller.cpp:1332-1333
へ渡り，速度ループの出力は機体座標系へヨー回転した後，微小角近似
$\theta \approx a/g$ により傾き指令へ写像される
（$\mathrm{pitch}_\mathrm{sp}=-a_{x,\mathrm{body}}/g$，$\mathrm{roll}_\mathrm{sp}=a_{y,\mathrm{body}}/g$% src: pid_controller.cpp:1350-1351
，重力加速度 $g=9.80665$\,m/s$^2$% src: sf_math.hpp:39, pid_controller.hpp:223
，$\pm 10$\textdegree（0.1745\,rad）% src: pid_controller.hpp:224
でクランプ）．傾き指令は姿勢ループ（PID，出力は角速度指令 $\mathrm{rate}_\mathrm{sp}$\,[rad/s]）% src: pid_controller.cpp:455-456
を経て，最内周の角速度ループ（PID，出力はトルク指令 [Nm]）% src: pid_controller.cpp:774-776
へ渡る．全段のPID制御器は共通の伝達関数

\[
C(s)=K_p\left(1+\frac{1}{T_i s}+\frac{T_d s}{\eta T_d s+1}\right)
\]
% src: pid.hpp:14
を持つ．ここで $K_p$ は比例ゲイン，$T_i$\,[s] は積分時間，$T_d$\,[s] は微分時間，
$\eta$ は不完全微分係数（既定 $\eta=0.125$）% src: pid.hpp:54
である．微分は目標値でなく測定値に作用させる方式（D-on-M）により目標値ステップでの
微分キックを避け% src: pid.hpp:20-31
，積分は台形則と条件付き積分アンチワインドアップ（出力が飽和方向に押される場合は
積分更新を停止する）を併用する% src: pid.hpp:108-133
．角速度ループが出力するロール・ピッチ・ヨートルクおよび鉛直推力指令は，
X型配置の4個のモータ% src: requirements.md:149-156
への推力配分（以下，ミキサ）によって個々のモータ回転数指令へ変換される．この
配分は，トルク［Nm］と推力［N］という物理量のままB$^{-1}$型の配分器で行う
% src: firmware/vehicle/components/sf_actuator/actuator.cpp:203-215, params.cpp:662-663
．
% TODO: カスケードブロック線図（後日TikZ、ブロック線図流儀に従い作成）

\subsection{状態推定}

状態推定には15状態の誤差状態カルマンフィルタ（Error-State Kalman Filter, ESKF）を用いる
（状態は位置・速度・姿勢誤差・ジャイロバイアス・加速度バイアスの各3次元）% src: eskf_core.cpp:14, eskf_core.hpp:36-40
．ESKFは各センサの到着レート（表1）で逐次観測更新する% src: eskf_core.cpp の各update関数
．オプティカルフローの生出力（画素変位）は，ジャイロ計測値を用いて回転による見かけの
流れ成分を除去したのち% src: eskf_core.cpp:751-752, eskf_core.hpp:88（flow\_gyro\_scale=1.0）
，ESKFの推定高度（ToF観測で拘束される）でスケーリングして機体座標系の並進速度に
変換し% src: eskf_core.cpp:756-757, eskf_estimator.cpp:146（-core_.getPosition().z）
，ヨー回転を経てNED座標の速度観測としてスカラー更新する% src: eskf_core.cpp:761-784
．スケーリングは推定器自身の高度による自己結合だが，ToFの直接観測に強く拘束される
ため線形化の範囲内として扱う．品質指標
SQUAL（センサが出力する画像品質の指標）が閾値（既定10）% src: eskf_core.hpp:100, params.cpp:808
を下回るサンプルおよび高度0.02\,m% src: eskf_core.hpp:89
未満のサンプルは観測から棄却する．外れ値混入への対策として，イノベーションに対する
$\chi^2$ゲート（自由度3，有意水準0.95に対応する閾値7.81）% src: eskf_core.cpp:448-462, params.cpp:812
をはじめとする複数のロバスト化機構を備える．

\subsection{SILS検証から実機発散，実効ゲイン同定，再設計まで}

SILSによる検証に合格したカスケードで臨んだ初の実機飛行（2026-06-22）では，
離陸から約15\,秒% src: 飛行窓14.51s, verification\_findings\_20260802.md \#1（確定）, paper\_figs.py flight\_window
のうちに水平方向の変位（動径 $r=\sqrt{x^2+y^2}$）が振動を伴いながら増大し，終端で約0.75\,mに達し% src: paper\_figs.py（r\_max=0.746 m at t=16.31 s）, logs/stampfly\_udp\_20260622T161055.jsonl
，壁への接触に至り推力を停止して飛行を終えた% src: verification\_findings\_20260802.md \#1（thrustカット）（図\ref{fig:divergence}）．この乖離の原因を探るため，
専用のスティック加振飛行データを用い，指令傾き（角度指令）とジャイロ積分による
実傾きとの回帰から姿勢達成度を，加速度の慣性積分によって得た速度とESKF出力速度
との回帰からオプティカルフロー由来の速度のスケールを，それぞれ切片なしの
最小二乗で同定した% src: analysis/scripts/poshold\_attID.py:161--195（gain\_no\_intercept，帯域通過後の回帰実装）
．同定飛行は高度維持モードでスティックが傾き指令に直結する構成（位置・速度ループを
経由しない）であり，外側ループとの相関によるバイアスを設計上避けている
% src: analysis/scripts/poshold\_attID.py docstring
が，姿勢・角速度ループは閉じたままで閉ループ同定のバイアスの可能性は残る．同定値
が別日・内側ゲイン約3倍変更後も同水準で再現されたことを頑健性の根拠とする
% src: verification\_findings\_20260802.md \#4
．指令傾きに対する実傾きの達成度は
$\approx 0.58$% src: verification\_findings\_20260802.md \#4（再現・頑健）, poshold\_journey.md:152-154
（0.15--3\,Hz帯域通過後の回帰値）% src: analysis/scripts/poshold\_attID.py:168,171
，オプティカルフロー由来の速度のスケールは $\approx 0.66$% src: verification\_findings\_20260802.md \#4
（0.1--2\,Hz帯域通過後の回帰値．通過帯域は姿勢達成度と異なる）% src: analysis/scripts/poshold\_attID.py:194-195
と同定した．両者の積として，実効的な「傾き→速度」ゲインは理想値 $g$ の
約0.4倍（$K\approx 0.4g\approx 3.9$\,m/s$^2$/rad）% src: poshold\_journey.md:150, verification\_findings\_20260802.md \#4
にとどまっていたことが分かった．カスケード制御は内側（速度）ループの応答が外側
（位置）ループより十分速いことを前提とする．実効ゲインの低下は速度ループの交差
周波数を下げてこの前提を崩し，むだ時間と積分の位相遅れが重なる低い周波数帯へ
交差周波数が落ちるため，単一ループの「ゲイン低下は安定側」という直感が成り立た
ない．線形カスケードモデルによる解析では，当時のゲイン
（位置ループ $K_p=1.0$，速度ループ $K_p=0.8$）% src: params.cpp履歴（コミット9a2c9dadから38dc38d8まで既定 pos.kp=1.0/vel.kp=0.8）
は，むだ時間 $L=150$\,ms% src: paper\_figs.py TAU\_PRIMARY=0.15s（K掃引の代表値）
において安定限界は $K/g\approx0.80$（むだ時間を0とした場合は$\approx0.65$）であり% src: task2\_results.json（σ=0交点の線形補間 0.793/0.647）
，これを下回ると不安定となる（例: $K=3.9$\,m/s$^2$/radで支配極の実部
$\sigma\approx+0.08$〜$+0.11$）% src: verification\_findings\_20260802.md \#5
．一方，SILSが内部プラントに仮定する理想ゲイン $K=g\approx9.81$\,m/s$^2$/radでは
安定（$\sigma\approx-0.07$〜$-0.12$）% src: verification\_findings\_20260802.md \#5
であり，この差がSILS合格・実機発散の乖離を説明する（図\ref{fig:stability}）．
% 注意: 「SILSで発散を再現した」とは書かない（sil_injection_20260802.md の帰結．3.3節は線形モデルの安定限界計算で乖離を説明する）
以上を踏まえ，単一の同定値への点校正ではなく，$K\in[2.8,7]$\,m/s$^2$/rad，
$L\in[50,300]$\,ms% src: poshold\_journey.md:175
という変動域全体で安定となるようカスケードを再設計した（速度ループゲイン
0.8→3.0，位置ループゲイン1.0→0.4）% src: poshold\_journey.md:170-173, params.cpp:771,773
．この再設計は同日中の実機飛行を経て，暫定値（位置ループ1.0→0.3，速度ループ
0.8→2.0）% src: poshold\_accel\_compensation.md:199-210（2026-06-22初回飛行時点の暫定値）
から，最終値（位置ループ0.4，速度ループ3.0）% src: poshold\_journey.md:170-173, params.cpp:771,773
へ確定した．

\section{小型機に特有の困難と対処}
\label{sec:difficulties}

開発過程では，小型機に特有ないくつかの困難に遭遇した．いずれもCrazyflieに
おける既報と対応付けられる現象であり，以下に本機での観測値と対処を示す
（表\ref{tab:difficulties}）．

第一に，電池電圧の低下である．3分間の連続したPOS\_HOLD飛行では，電池電圧が
離陸直後の3.87\,Vから飛行終盤の3.49\,V程度まで低下し
% src: analysis/reports/poshold_3min_battery_wobble_20260627.md:27,29

下回る後半では 59〜118\,mm へ増大した
% src: analysis/scripts/verify_hikoki64/review_A1_battery_corr.py（20s窓・離陸過渡窓除外の盲検再計算）
．推力指令のデューティ変換ではリアルタイムの電源電圧で補償しており
% src: firmware/vehicle/components/sf_actuator/actuator.cpp:105-108,117

% src: analysis/reports/poshold_3min_battery_wobble_20260627.md:14-15,49

Crazyflieでも電池電圧の低下に対する補償式が示されている\cite{giernacki2017}．

第二に，モータのトルク効きと個体差である．実機モータの実効トルクは理論値の
0.4〜0.7倍にとどまる
% src: firmware/vehicle/docs/control_theory_overview.md:166

設計した（3.3節）．Crazyflieでも個体ごとのモータ推力特性の同定が報告されて
いる\cite{forster2015,eschmann2024}．

第三に，オプティカルフローの床面依存である．3.3節で同定した速度スケール

% src: docs/hikoki64/MANUSCRIPT_PLAN.md:69（4章の防御問答）

ト設計（3.3節）で対処した．本機でのフロー品質は良好であった（SQUAL中央値
160）
% src: analysis/reports/poshold_3min_battery_wobble_20260627.md:79

飛行データの自然なゆらぎから推定すると，0.08〜0.16\,Hz（0.5〜1\,rad/s）の帯域では
$\approx$0.21--0.29と，広い帯域（0.03〜0.5\,Hz，0.2--3\,rad/s）での$\approx$0.62--0.69
より明確に小さく，周波数依存が見られる
% src: docs/hikoki64/prep/verification_findings_20260802.md 新たに判明した事実2
．低周波ほど減衰する形は速度比例抗力によるロータ抗力の予言と定性的に一致するが，
定量的な機構の解明は残されている．第三に，姿勢達成度にはロール・ピッチ間の非対称が
見られ，pitch軸（0.85--0.97）がroll軸（0.58--0.68）より明確に良い
% src: docs/hikoki64/prep/verification_findings_20260802.md 新たに判明した事実3
．第四に，2章で述べたSILSのモデル一致ゲートはロール・ピッチ軸で合格する一方，
ヨー軸は不合格のままである
% src: docs/hikoki64/prep/gap/sf_ecosystem.md §2.6, docs/architecture/simulation-policy.md §4
．このほか，表\ref{tab:difficulties}に残存として示した低電圧域の非線形性，
モータ個体差および床面条件の定量的な評価も今後の課題である．

今後の発展としては，軌道追従機能の実装，\texttt{IController}インターフェース
（実装済み）を介した代替制御器の追加，外部測位をESKFへ加える経路の整備，
複数機運用に向けたESP-NOWの拡張が挙げられる
% src: docs/hikoki64/prep/crazyflie_gap_analysis.md §3, firmware/vehicle/docs/detailed_design.md:262（IControllerインターフェース）

\section{まとめ}
% 内容メモ（0.5p想定、参考文献10件込み）:
% v3計画: 要約（パラメータ開示・設計手順・小型機の困難・開発基盤）＋文献12件。
% 用語注意: 「還流」禁止（→反映）。「飛行ログ」禁止（→飛行データ）。
% TODO: 本文執筆（4・5章の確定後に清書）。
本稿では，質量37\,gのクアッドロータ StampFly を対象に，位置制御系の開発過程を
報告した．実機と同一ソースコードを無改変で実行するSILSによる検証基盤（2章）の
上でカスケードPID構造による位置制御系を設計し，SILS合格ながら実機飛行で発散
した経緯から傾き→速度の実効ゲインを同定，変動域全体でロバストに安定となるよう
再設計して手放しでの位置保持を実現した（3章）．電池電圧の低下，モータのトルク
効きと個体差，オプティカルフローの床面依存という小型機に特有の困難をCrazyflie
における既報と対応付け（4章），到達点と残存課題および開発基盤の現状を示した
（5章）．今後，StampFlyを制御工学の学習・研究に用いる人にとっての参照起点と
なることを意図する．
